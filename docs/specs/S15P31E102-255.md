# Mattermost Push 커밋 구분

일반 Push 알림은 `변경 커밋 N개 · 병합 커밋 M개`로 표시하고 변경 커밋만 시간순 링크 목록에 표시한다. 새 브랜치 안내는 유지한다. 부모가 2개 이상이면 병합, 0~1개이면 변경으로 분류한다. 제목은 판단 근거가 아니다.

GitLab Push 목록이 잘렸거나 부모 정보가 없으면 straight compare로 정확한 before..after 범위를 보완하고 필요한 커밋 상세를 조회한다. 누락·중복·잘린 비교 결과를 정상 집계로 보내지 않는다. 조회 실패는 기존 제한된 재시도 정책을 따른다. 이전 큐 payload도 전송 직전에 보완한다. 기존 MR·질문·댓글 안내, 목적지와 비밀값은 변경하지 않는다.
